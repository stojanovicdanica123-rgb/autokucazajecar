# Auto kuća Zaječar – sajt

Statični sajt (jedan `index.html` + folder `assets/`).

## Objavljivanje na GitHub Pages
1. Napravite novi repozitorijum na GitHub-u i ubacite sadržaj ovog foldera (`index.html`, `assets/`, `README.md`) u koren.
2. Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, folder `/ (root)` → Save.
3. Sajt će biti dostupan na `https://<korisnik>.github.io/<repo>/` za minut-dva.

Za sopstveni domen (npr. autokucazajecar.com): Settings → Pages → Custom domain.
